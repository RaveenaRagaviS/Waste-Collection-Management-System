
# Waste Collection Data Analysis

## Overview
This module analyzes waste collection data stored in the SQLite database using Python.

## Technologies Used
- Python
- Pandas
- Matplotlib
- SQLite

## Features
1. Database summary
2. Staff details
3. Waste reports by category
4. Collection staff performance
5. Collection quantity by category
6. Collection request status analysis
7. Area-wise collection performance

## Installation

Install the required packages:

```bash
pip install -r requirements.txt
```

## Execution

Run the following command from the project root:

```bash
python python-analysis/analysis.py
```

## Output
Charts are saved in the `python-analysis/output` directory.

## Database
The analysis reads data from:

`database/waste_collection.db`
